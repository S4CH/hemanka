# HOUSE OF HEMANKA

A responsive editorial fashion storefront for HOUSE OF HEMANKA, presenting modern Indian heirlooms through a luxury campaign experience.

## Features

- Responsive desktop, tablet, and mobile layouts
- Full-screen editorial campaign hero
- Search with live product filtering
- Persistent shopping bag with quantity controls
- Accessible menu and utility drawers
- Newsletter submission state
- Reduced-motion support
- Touch-friendly mobile controls

## Local preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765`.

## Verification

```sh
node --test test.mjs
node --check script.js
```
